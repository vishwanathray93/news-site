News-Website

A custom CMS-powered blog built using PHP, jQuery, and AJAX. This project allows users to read news articles, while admins can manage content dynamically without page reloads.

Features

User-friendly CMS for managing news articles

AJAX-based operations for seamless user experience

Admin panel for adding, editing, and deleting news articles

Dynamic category and author management

Comment system with moderation

Search functionality for articles

Responsive design for mobile and desktop

Technologies Used

Frontend: HTML, CSS, JavaScript, jQuery, AJAX

Backend: PHP (Core PHP, no framework)

Database: MySQL

Installation

Clone the repository:

git clone https://github.com/yourusername/news-website.git

Navigate to the project directory:

cd news-website

Import the database:

Create a MySQL database

Import the news_website.sql file located in the database/ directory

Configure database connection:

Edit config.php and update your database credentials

Start a local server using XAMPP or another PHP environment

Open the project in your browser:

http://localhost/news-website

Admin Panel

Access the admin panel at:

http://localhost/news-website/admin

Default Admin Credentials:

Username: admin

Password: admin123

Usage

Users can browse, search, and read news articles

Admins can log in to create, edit, and delete articles

Comments can be posted and moderated by admins
